
# Study Planner

A Flutter capstone project designed to help students
organize and manage their study activities.

## Project goals

- Build a consistent, responsive application.
- Support Android and Web.
- Develop features incrementally according to the capstone tasks.

## Technology stack

- Flutter
- Dart
- Visual Studio Code
- Git and GitHub

## Prerequisites

- Flutter SDK
- Dart SDK supplied with Flutter
- Git
- Android SDK and emulator/device for Android testing
- A supported browser for Web testing

## Getting started

Clone the repository and enter the project directory:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd study_planner
```

Install project dependencies:

```bash
flutter pub get
```

Run static analysis and tests:

```bash
flutter analyze
flutter test
```

Run on Web:

```bash
flutter run -d chrome
```

Run on Android:

```bash
flutter devices
flutter run -d YOUR_DEVICE_ID
```
